Modules, Packages, JSON and Logging

Practical assignment on today's session. Sample data: DATA/readings.csv.

A. Modules and imports

  1. Unit converter module: Create converter.py with c_to_f(c) and km_to_miles(km). In a separate app.py, import both with from converter import ... and print one example of each.
  2. Extend calculator: Add subtraction(a, b) and calcArea(radius) to calculator.py, then call them from main.py.
  3. Import styles: In one file use import calculator (call as calculator.addition(...)), and in another use from calculator import addition as add. Print the same result both ways.

B. Packages

  1. Build a package: Create bench_tool/labtools/ with an empty __init__.py. Add instruments.py containing a PowerMeter class with connect() and disconnect().
  2. Use the package: In bench_tool/main.py import PowerMeter with from labtools.instruments import PowerMeter, create one on port "COM3", then connect and disconnect.
  3. Second instrument: Add a TempSensor class to instruments.py with a read() method that returns a fixed value. Use both classes in main.py.

C. JSON configuration

  1. Write a config: Build a dict with station, instrument (model, port, timeout_s), channels, limits (power_mw_min, power_mw_max) and save_raw. Save it to config.json with json.dump and indent=2.
  2. Read a config: Load config.json with json.load and print the port and both limits using chained keys.
  3. Pass / Fail report: Using the limits from the config, print time channel power Pass/Fail for every good row of readings.csv.
  4. Type check: Dump a dict containing True, None and a tuple, then read the file as text and write a comment listing how each became JSON.

D. Logging

  1. Levels: Configure logging.basicConfig with level INFO and the format %(asctime)s %(levelname)-8s %(message)s. Log one message at each of DEBUG, INFO, WARNING and ERROR, and note which one does not appear.
  2. Log to file and screen: Add a FileHandler("run.log") and a StreamHandler() so every message goes to both. Check that run.log has the lines.
  3. Log an exception: Wrap float("ERR") in try/except and use logging.exception. Explain in a comment what extra information it adds compared to logging.error.

E. Putting it together

  1. Analysis module: Create labtools/analysis.py with load_reading(path). Use log = logging.getLogger(__name__) and log.warning("line %d skipped : %s", line_no, e) for every row that fails conversion; return the good rows.
  2. Final run: In bench_tool/main.py call basicConfig once, load the config and readings.csv through load_reading, and log how many rows passed and failed against the config limits.
